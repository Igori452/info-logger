# Система логирования (Тестовое задание C++)

Проект выполнен в соответствии с [Техническим заданием ИнфоТеКС](docs/Razrabotchik-C_.pdf).

Данный проект состоит из библиотеки для записи сообщений в журнал и консольного многопоточного приложения для демонстрации и проверки её работы, разработанных в рамках тестового задания ИнфоТеКС.

## Быстрый старт

Для компиляции используется компилятор **GCC** в среде **Ubuntu 24.04** через Docker.

### 1. Подготовка окружения (Docker)
Соберите и запустите контейнер из корня репозитория:
```bash
docker build -t logger-env .
docker run -it -d -v \$(pwd):/workspace logger-env
```

### 2.1 Сборка в СТАТИЧЕСКОМ режиме (Часть 1)
Внутри контейнера выполните:
```bash
mkdir -p build && cd build
cmake -DBUILD_SHARED_LIBS=OFF -DBUILD_TESTS=ON ..
make 
```

### 2.2 Сборка в ДИНАМИЧЕСКОМ режиме (Часть 1)
Внутри контейнера выполните:
```bash
mkdir -p build && cd build
cmake -DBUILD_SHARED_LIBS=ON -DBUILD_TESTS=ON ..
make
```

### 3. Консольное многопоточное приложение (Часть 2)
Приложение считывает пользовательский ввод в цикле и мгновенно передает его в отдельный фоновый рабочий поток через потокобезопасную очередь, обеспечивая отзывчивость интерфейса.

**Использование клиента:** `./build/app/app <уровень_важности_по_умолчанию> <путь_к_файлу>`

Запустите приложение (например, для записи в файл `log.txt` с уровнем фильтрации `INFO`):
```bash
./build/app/app INFO log.txt
```
После запуска вводите текстовые сообщения и уровни важности прямо в консоль приложения.


### 4. Сервер сбора сетевой статистики (Часть 3)
Сервер принимает данные от логгера, рассчитывает метрики (минимум, максимум, среднюю длину сообщений и т. д.) и выводит отчет в консоль по двум триггерам: каждые \(`N`\) сообщений или по таймауту \(`T`\) секунд неактивности (только если статистика изменилась).

**Использование сервера:** `./build/socket_app/socket_app <IP> <порт> <таймаут_T_сек> <триггер_N_сообщений>`

Запустите сервер в первом терминале контейнера (например, слушать локальный порт `8888`, таймаут `5` секунд, триггер каждые `2` сообщения):
```bash
./build/socket_app/socket_app 127.0.0.1 8888 5 2
```

#### Быстрое интерактивное тестирование через Netcat
Вы можете проверить сетевой ранер вручную без использования демонстрационного приложения. Для этого откройте **второй терминал** внутри этого же Docker-контейнера и подключитесь к серверу через штатную утилиту `nc`:

1. Подключитесь к сокету сервера:
   ```bash
   nc 127.0.0.1 8888
   ```
2. Консоль перейдет в режим ожидания ввода. Скопируйте и вставьте туда валидную строчку лога, после чего обязательно нажмите **Enter** (чтобы отправился разделитель `\n`):
   ```text
   [ 2026-08-25 12:00:00 ] [ INFO    ] Тестовое сообщение через сетевой ресивер.
   ```
3. Вы мгновенно увидите реакцию и вывод строки в окне запущенного сервера. 
4. Нажмите **Ctrl + C** в терминале с `nc`, чтобы разорвать соединение. Сервер зафиксирует дисконнект и мгновенно напечатает итоговую таблицу со всеми рассчитанными метриками.
