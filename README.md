# Система логирования (Тестовое задание C++)

Данный проект состоит из библиотеки для записи сообщений в журнал и консольного многопоточного приложения для демонстрации и проверки её работы, разработанных в рамках тестового задания ИнфоТеКС.

## Быстрый старт

Для компиляции используется компилятор **GCC** в среде **Ubuntu 24.04** через Docker.

### 1. Подготовка окружения (Docker)
Соберите и запустите контейнер из корня репозитория:
```bash
docker build -t logger-env .
docker run -it -d -v \$(pwd):/workspace logger-env
```

### 2.1 Сборка в СТАТИЧЕСКОМ режиме (`BUILD_SHARED_LIBS=OFF`)
Внутри контейнера выполните:
```bash
mkdir -p build && cd build
cmake -DBUILD_SHARED_LIBS=OFF -DBUILD_TESTS=ON ..
make 
```

### 2.2 Сборка в ДИНАМИЧЕСКОМ режиме (`BUILD_SHARED_LIBS=ON`)
Внутри контейнера выполните:
```bash
mkdir -p build && cd build
cmake -DBUILD_SHARED_LIBS=ON -DBUILD_TESTS=ON ..
make
```

## Запуск компонентов (из папки `build`)

### Демонстрационное приложение
Использование: `./app/app <уровень_важности_по_умолчанию> <путь_к_файлу>`

Запуск проекта (работает одинаково для статического и динамического режимов):
```bash
./app/app INFO log.txt
```
*(Примечание: При сборке в динамическом режиме CMake автоматически прописывает `RUNPATH` к библиотеке `logger_lib`).*

### Автоматическое тестирование (`CTest`)
Запуск всех юнит-тестов:
```bash
ctest --output-on-failure
```

или:

```bash
./tests/unit_tests
```
