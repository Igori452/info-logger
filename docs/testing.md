## Описание юнит-тестов
Тесты написаны без использования сторонних фреймворков (Google Test / Catch2) строго с использованием стандартной библиотеки:
1. `test_logger_with_mock` — проверка логики логгера через подставной (Mock) интерфейс вывода.
2. `test_logger_with_file` — проверка корректности создания реального файла и записи строк.
3. `test_thread_manager_queue` — базовая проверка корректности работы потокобезопасной очереди FIFO в приложении.
4. `test_thread_manager_stop_operation` — проверка корректного завершения потоков приложения при вызове `stop()`.
5. `test_thread_manager_error_operation` — проверка перевода менеджера в аварийный режим при критических ошибках диска.
6. `test_thread_manager_with_two_thread` — стресс-тест приложения на состояние гонки (Race Condition) с параллельными потоками Producer и Consumer.
