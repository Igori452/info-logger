# Техническая документация проекта info-logger

Добро пожаловать в руководство по архитектуре и внутреннему устройству проекта. Здесь подробно описаны проектные решения, которые обеспечивают производительность, безопасность и гибкость системы.

## Общая навигация по репозиторию

```text
.
├── docs/                       # Подробная документация к проекту
├── CMakeLists.txt              # Корневой файл сборки
├── Dockerfile                  # Окружение для сборки и тестирования (Ubuntu 24.04 + GCC)
├── README.md                   # Обзор проекта
├── logger_lib/                 # Часть 1. Библиотека логирования (синхронная)
│   ├── CMakeLists.txt
│   ├── include/logger_lib/     # Публичные заголовочные файлы библиотеки
│   └── src/                    # Реализация интерфейсов вывода, логирования и кодов ошибок
├── app/                        # Часть 2. Консольное многопоточное приложение
│   ├── CMakeLists.txt
│   ├── ThreadManager/          # Ядро приложения (Менеджер потоков, очередь, рабочий поток)
│   └── main_app.cpp            # Точка входа (поток чтения cin)
└── tests/                      # Раздел юнит-тестирования
    ├── CMakeLists.txt
    ├── AppTests/               # Тесты менеджера потоков и многопоточности приложения
    ├── LoggerLibTests/         # Тесты внутренней логики библиотеки логгера
    └── main_tests.cpp          # Точка входа для тестов
```


## Содержание

### [Глава 1. Архитектура и дизайн системы](architecture.md)
Описано строгое разделение проекта на два независимых слоя: синхронное ядро логирования (`logger_lib`) и асинхронный слой управления потоками (`app_core`). Рассмотрены ключевые классы библиотеки (`Logger`, `LoggerMessage`, `OutputInterface`), система кодов ошибок на базе `std::error_code` без использования исключений, а также реализация паттерна Producer-Consumer в приложении с безопасной остановкой и аварийным режимом при критических ошибках.

### [Глава 2. Стратегия тестирования и верификация](testing.md)
Описана стратегия тестирования проекта без использования сторонних фреймворков, строго на стандартной библиотеке C++. Представлены две группы тестов: для синхронного ядра (`logger_lib`) с проверкой фильтрации, форматирования и файлового вывода, и для асинхронного слоя (`app_core`) с проверкой работы потокобезопасной очереди, штатной и аварийной остановки, а также многопоточных сценариев Producer-Consumer.
